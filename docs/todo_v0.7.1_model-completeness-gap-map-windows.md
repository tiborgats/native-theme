# Gap map — Windows 11 (WinUI 3 / Fluent 2, preset `windows-11`)

Model compared: `docs/property-registry.toml` at caeddd6b (branch `v0.7.1-rc1`), `AccessibilityPreferences`
(`native-theme/src/lib.rs:415-437`), `docs/inheritance-rules.toml`; what is already sourced: `docs/platform-facts.md`
§1.2 and the Windows columns of Chapter 2; what the OS probe already reads: `tools/os-probe/src/windows.rs`
(queries only — GetSystemMetricsForDpi, GetSysColor, NONCLIENTMETRICS, 22 SPI values, UISettings colours and four
flags, AccessibilitySettings, DwmGetColorizationColor, three registry keys; **no renders**).

**Citation base.** "MUX" = microsoft-ui-xaml at `ba3a8d59e6de4e2b86ca4f61c78bc26ccf129afd` (tag `winui3/release/2.5.1`, the 0.8.0 pin; re-pinned 2026-10-30 from `8463f451`, the commit platform-facts
cites), paths relative to `src/controls/dev/` unless they start with `dxaml/` (then relative to `src/`). A resource key is cited at the line where
its `Default` (dark) dictionary or its only definition states it; the Light and HighContrast dictionaries of the same
file restate it. "Learn" = learn.microsoft.com, read 2026-10-27, with the page's `updated_at`.
Source kinds: **read** (run-time API), **published** (MUX / Learn / Fluent 2), **measure** (method named). "to verify"
marks an API or location not confirmed in this pass.

Method notes:
- A row is a gap only where the registry has no field; "partial" marks a field that exists but cannot hold what
  Windows draws (one colour where it draws several, one state where it draws a state matrix, a bool where it draws
  geometry).
- WinUI's state matrix is uniform: almost every control has Background / Foreground / BorderBrush × Normal,
  PointerOver, Pressed, Disabled (plus Checked/Selected/Indeterminate variants). The model's general pattern
  (`background_color`, `hover_background`, `active_background`, `disabled_*`) covers a subset; every missing cell of
  that matrix is listed per control below.
- No values were collected (the method's rule). A few numbers appear only where they were read in the cited line and
  identify *which* resource is meant.
