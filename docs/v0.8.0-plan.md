# native-theme v0.8.0 — Implementation Plan

**Status:** Self-contained execution plan pairing with [v0.8.0-spec.md](v0.8.0-spec.md). *(Implementing sessions — e.g. Claude Code / Opus 5.5 — need **only** `docs/v0.8.0-spec.md` and `docs/v0.8.0-plan.md`; do not load `docs/v0.8.0-rationale.md`, which is background design history.)*
**Branch:** `v0.8.0` (branched from `main` / `v0.7.2`; `v0.8.0-rc1` kept untouched as read-only salvage source).
**Goal:** Ship a fast, small, 1.0-ready `v0.8.0` across 4 vertical milestones (`M1`–`M4`) with minimal token overhead and fast compile-test loops, without compromising native visual fidelity or test rigor.

## 1. Speed & Token-Efficiency Protocol (Zero Quality Loss)

Every rule below cuts compile time, code duplication, and context size while keeping verification strict:

1. **Salvage verified code directly via `git checkout` — never rewrite solved math or parsers:**
   - Pull 20 verified platform math kernels (`src/platform/*`, excluding `ripple.rs` and expression-VM glue `kde_accent_operands.rs`), all 4 clean-room parsers (`src/cleanroom_readers/*`, which have zero `crate::` imports), 23 golden TSV vector tables (`tests/vectors/*`), `native-theme/NOTICE` (stripping `src/ripple.rs` notices), and vector generators (`tools/*-vectors`) straight from `v0.8.0-rc1`.
   - Keep `platform/` and `cleanroom_readers/` strictly `pub(crate)`, keep internal `kde_color_common::Rgba` untouched (converting to/from `Color` at preset boundaries), and run `v0.8.0-rc1`'s vector checks as `#[cfg(test)]` unit tests inside `src/platform/vector_tests.rs` (avoiding leaking 20+ internal platform helper modules/enums into the public 1.0 API).
   - Keep `main`'s `src/kde/qt_color_vectors.rs` (16-bit PySide6 precision rounding vectors) inside `#[cfg(test)] src/platform/`. Only **one** new math kernel needs authoring: clean-room `platform/qt_lighter.rs` + its golden vector table (Issue #4 `L3`).
2. **Isolate crate rebuilds (`-p native-theme`) during `M1`–`M3`:**
   - Do not carry a parallel `0.7.2` + `0.8.0` dual model inside `native-theme`. Make a clean cut in `M1` and iterate strictly with `cargo test -p native-theme` (~2–5 s cycles) instead of rebuilding `gpui`, `iced`, and `egui` on every edit.
   - Port `tools/showcase-support` and each connector one crate at a time in `M4`, running the full `--workspace` gate at the end of `M4`.
3. **Eliminate preset boilerplate with a shared `presets/helpers.rs` scaffold:**
   - Centralize the 4-step pipeline glue (`SystemOverrides`, `Palette`, `accent`, `font_dpi`/`text_scale`, `bold_text`, `motion`, `direction`, icon theme selection, `ResolvedTheme.name`), `RuleBuilder`, `oklch_accent_ramp`, and mobile `synthesize_desktop_widgets` in ~150–200 lines of `presets/helpers.rs`.
   - Share `presets/macos.rs` (`macos-monterey` + `macos-tahoe`) and `presets/ios.rs` (`ios-13` + `ios-26`) so all 8 presets live in **6 concise files** (~350–600 LOC each) with inline upstream citations.
4. **Load one platform reference at a time:**
   - When writing a single preset file (e.g., `presets/adwaita.rs`), consult only that platform's local reference (`docs/todo_v0.8.0_model-completeness-gap-map-<platform>.md`, `docs/platform-facts.md`, `docs/issues/0004_kde-leftovers-rationale.md`, or pinned upstream versions in `git show v0.8.0-rc1:docs/facts/sources.toml`) — never load all 6 gap-maps into context simultaneously, and never copy LGPL/GPL upstream source code.
5. **No meta-machinery or throwaway prose:**
   - Zero Python preset codegen, zero 66 MB fact DB, zero doc-linter loops, zero per-widget markdown catalogues. Rust's type system, `size_of` tests, counting-allocator zero-alloc tests, golden vector tests, and the invariant matrix enforce all contracts directly.
6. **Small, bisectable commits:**
   - Commit at each milestone boundary (`docs`, `M1`, `M2`, `M3a`, `M3b`, `M4a`, `M4b`, `M4c`) with green checks before moving on.

## 3. Risks & Mitigations

| Risk | Mitigation |
|---|---|
| Platform reader regressions on macOS/Windows (not runnable on Linux CI host) | Preserve existing FFI bindings & `// SAFETY:` invariants from `0.7.2`; keep OS-specific logic behind pure testable parsing/mapping helpers (unit-tested on Linux) + `cargo check` cross-target review. |
| Preset size or `resolve()` latency creep | Run `size_of`, heap-estimate, and release timing tests in `M1`/`M3`; keep shared `PresetScaffold` and flat `Arc<[P]>` buffers. |
| Accidental drift from native upstream values | Every native value in `presets/*.rs` carries an inline upstream citation; all 24 derivation kernels run golden vector tests; `os-probe` outputs remain reference ground truth. |
| Connector compilation slowdown during core work | Keep `M1`–`M3` strictly inside `-p native-theme` (and `-p native-theme-build`); only rebuild connectors one-by-one in `M4`. |
